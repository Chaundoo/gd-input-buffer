# Input Buffer

Practice tool: extends quick taps so they stay held for a minimum number of physics ticks (GD runs 240 ticks/s, so 4 ticks = 1 frame at 60 fps).

Press **F6** inside a level to cycle: 2/2 → 4/4 → 8/8 → 16/8 → OFF (ticks for all gamemodes / ticks for wave).

Runs made with this enabled are not legitimate and should not be submitted to leaderboards or the Demonlist.
